# Sicurezza

## Versioni supportate

La versione pubblicata più recente è l'unica supportata con correzioni di sicurezza.

## Segnalare una vulnerabilità

Non pubblicare dettagli sensibili in una issue. Utilizza la funzione **Report a vulnerability** nella sezione **Security** della repository GitHub. Includi una descrizione, i passaggi per riprodurre il problema, l'impatto e l'eventuale correzione proposta.

Le normali segnalazioni prive di implicazioni di sicurezza possono essere aperte come issue pubbliche.
