# Contribuire a Forgia dell'avventuriero

Grazie per voler migliorare il progetto. Segnalazioni, correzioni e pull request sono benvenute.

## Prima di iniziare

- apri una issue per modifiche ampie o incompatibili;
- non copiare testi da manuali non inclusi nelle fonti autorizzate;
- indica sempre la provenienza e la licenza dei nuovi dati;
- per nuovi oggetti magici conserva rarità, requisito di sintonia e fonte; rappresenta gli effetti numerici anche nei campi strutturati;
- non includere dati personali, segreti, token o materiale di terzi privo di autorizzazione;
- mantieni tutte le misure in metri e chilogrammi.

## Controlli richiesti

Installa le dipendenze con `npm ci`, quindi esegui:

```bash
npm run verify
```

Per modificare i cataloghi è disponibile l'editor locale:

```bash
npm run catalog:editor
```

## Licenza dei contributi

Inviando un contributo dichiari di avere il diritto di fornirlo e accetti che:

- codice e documentazione originale siano distribuiti secondo la licenza MIT del progetto;
- i contributi che modificano Open Game Content siano distribuiti secondo la Open Game License 1.0a;
- contenuti di terzi mantengano la loro licenza e attribuzione originale.

I contributi derivati dall'edizione italiana SRD 5.1 devono mantenere l'attribuzione CC BY 4.0 indicata in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). Non mescolare nello stesso record testi provenienti da manuali non inclusi nelle fonti autorizzate.

Il progetto può rifiutare contributi la cui origine o compatibilità di licenza non sia verificabile.
